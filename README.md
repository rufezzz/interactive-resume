# Interactive Resume

Интерактивное резюме Web-разработчика.

## О проекте

Проект содержит информацию обо мне, образовании, навыках, проектах и контактах.

На странице реализованы фильтрация и поиск навыков, а также переключение между светлой и темной темой.

## Опубликованный сайт

https://rufezzz.github.io/interactive-resume/

## Выполненные требования

- Создан публичный GitHub-репозиторий;
- Резюме содержит реальные сведения обо мне;
- Страница нормально выглядит на комьютере/телефоне;
- Отсутствует горизонтальная прокрутка на мобильном устройстве;
- Фильтрация навыков;
- Поиск навыков;
- Поиск и категории работают одновременно;
- Состояние "ничего не найдено" отображается корректно;
- Переключение между светлой и тёмной темой;
- Тема сохраняется после обновления страницы;
- Проект опубликован через GitHub PAges;

## Дизайн-референс

При разработке внешнего вида сайта в качестве визуального референса использовался сайт:

https://georgesergeev.ru/

Из референса была взята общая идея расположения и структуры элементов страницы. Цветовая гамма и оформление проекта были адаптированы под собственный вариант.
